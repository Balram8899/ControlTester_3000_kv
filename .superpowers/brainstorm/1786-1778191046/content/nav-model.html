How should users move through the pipeline?

The current page dumps all 5 stages onto one view. Which navigation model should replace it?

A

Linear Wizard / Stepper

Each stage is a discrete page. A top stepper bar shows progress. Users click "Next" to advance — the system can also auto-advance when a stage completes. Breadcrumb: Setup → Upload → Review → Export

① Setup ── ② Upload & Tag ── ③ Review ── ④ Export
  • Clear sense of progress
  • Each stage is focused, uncluttered
  • Matches pipeline linearity
  • Users can't glance at later stages
  • Back-navigation needs careful handling
B

Tabbed Stages (same page)

A horizontal tab bar at the top of the case detail. Tabs are enabled/disabled based on pipeline stage. Users can freely jump to any unlocked tab.

Documents Processing Review (12) Export
Tab content here…
  • Easy to jump back and re-check
  • Familiar pattern
  • Stays on one URL/case
  • Doesn't feel like a workflow
  • Less obvious what to do next
C

Case Dashboard + Drill-Down Pages

A case summary card shows status at a glance. Each stage (Documents, Review, Export) is a separate sub-page you navigate into. The case list stays persistent in a left sidebar.
